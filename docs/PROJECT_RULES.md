# YadiLab project rules

Authoritative architecture: YadiLab Masterprompt v1.3 VERIFIED / LOCKED.

## Checkpoint persistence rule

Every completed YadiLab checkpoint/release must be:

1. packaged as a versioned artifact;
2. accompanied by a SHA-256 checksum file;
3. uploaded to Google Drive under `YadiLab/Releases` before work continues to the next checkpoint.

This is a standing project rule unless Daniel explicitly changes it.
