# YadiLab Foundation v0.78.0

Phase 78 introduces **Guided Lab / Scenario Curriculum Wave 1**.

Highlights:

- eight built-in offline troubleshooting labs: four Windows and four Linux;
- gateway, DNS, host-firewall and RDP/SSH service failure families;
- direct `Start guided lab` Runtime launch plus `Open lab in Builder` author path;
- learner-visible catalog contains no solution/remediation parameters;
- transparent four-dimensional difficulty metadata only;
- every lab uses existing evidence objectives, active probes, notebook, guided workflow and typed remediation;
- all eight lab flows have deterministic test-only acceptance from broken baseline to `VERIFIED_IMPROVEMENT` and `VERIFICATION_COMPLETE`;
- no live connector, guest command execution, automatic diagnosis, automatic fix or hidden score.

Classification remains **VERIFIED DEVELOPMENT CHECKPOINT, NOT VERIFIED PRODUCT RELEASE** until the external dependency/browser/Parrot release gates are actually satisfied.
