# AUDIT-007 P6 — FROZEN fd-confinement / symlink-race acceptance

**Frozen first, source unchanged:** protected base `b8b52039794b8435cfb3cdf3747a27dee2711652` tree `e4aae3099e85f75619a987fe817062a9e9fb3396`; authoritative [AGENTS.md](../../AGENTS.md) and full bug-first [AUDIT-007 issue #96](https://github.com/Northsw-spec/YadiLab/issues/96). **Source-grounded risk:** `launcher/server.go` uses `resolve()` to `os.Stat`, `filepath.EvalSymlinks` and check that a path lies below `s.root`, returns a **string**, then `ServeHTTP` separately `os.Open(path)`. A pathname or symlink replacement between check and open would invalidate the earlier security decision. This is a plausible TOCTOU disclosure issue, **not automatically evidence of real outside-content disclosure**; distinguish deterministic reproduced behavior from inferred consequences.

**Frozen Go real HTTP negative/positive proof** `launcher/audit007_p6_fs_atomic_open_test.go`:
1. Deterministic actual `staticServer.ServeHTTP`: after constructing a server with in-root `index.html`, rename the originally trusted `web/` directory and replace the old path by a symlink to another directory containing an outside canary. GET `/` must serve *original pinned bytes* (200) and never another directory's bytes. Old path-based source returns 404: **a separately reproducible root-path identity/availability defect**, not itself proof of confidentiality leakage. Source fix must capture trusted root directory FD at startup.
2. Fail closed on **all symlinks** including those currently pointing back inside the root, in both terminal filename and intermediate directory components, to avoid post-check symlink redirection. Preserve direct nested real files.
3. External symlink to file and directory must remain denied (HTTP 404; canary never present).
4. Valid `/manual` and `/manual/` nested index routes must still return the same content; HEAD must respond 200 with correct size but no response body.
5. Go AST-only supplemental control forbids `ServeHTTP` from independently `os.Open(path)` on a previously resolved pathname. This is not presented as standalone behavioral proof.

**Patch design:** no new third-party library or toolchain bump. Use already pinned Linux x86_64 Go 1.23 `syscall.Openat`, starting from a trusted directory descriptor opened in the constructor and held for server lifetime. Walk every URL path component relative to previously opened directory descriptors using `O_NOFOLLOW` and `O_DIRECTORY` for intermediate components; derive directory index via the already open fd; check `f.Stat().Mode().IsRegular()` on final file descriptor; read/serve that same fd, **never close then reopen by pathname**. Explicitly close root fd at server shutdown. Symlinks inside the root will now be denied (deliberate fail-closed policy). Continue to forbid NUL/backslash, unsafe encoded slash/dot, methods other than GET/HEAD and retain MIME/CSP/security headers and exact-once decoded path logic from P5. Document limitations: same-UID actors able to rewrite regular file *contents* are outside the file-system-confinement guarantee; FD lifetime and root initialization still need permission review.
