## Verified problem

The bounded Nessus v2 parser accepts up to **256 ReportHost elements**, structurally validates each and produces ONLY `hostCount`, `findingCount`, aggregate severity counts and original SHA. It deliberately destroys host identifiers, IPs, plugin output and vulnerability details. Current P3 review shows only 20 source ordinals and its pure validator denies `hostOrdinal>=20` even if the original source has 256. The intended security cap of **20 explicitly selected associations** need not prohibit reaching a later original ordinal.
