## Actual gap
The canonical `Metadata/Nodes/Interfaces/Links/Zones/Layout` XLSX/ODS path maps explicit `Links.interfaceA/interfaceB` names to modeled edge endpoints, but presently checks only that their nodes exist, **not that the specified interface IDs are actually declared on those nodes**. A typo such as `interfaceA=missing` must never enter the modeled topology as if a real port was documented. Duplicate interface IDs scoped to a node are also ambiguous. A declared gateway/address without a `Links` row must not become a connection.
