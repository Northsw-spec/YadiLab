External standards: OASIS OpenDocument v1.3 Part 2 Packages https://docs.oasis-open.org/office/OpenDocument/v1.3/OpenDocument-v1.3-part2-packages.html — text ODT MIME, mimetype file first in ZIP, stored/uncompressed and no extra; package manifest. OASIS v1.3 Part 3 Schema https://docs.oasis-open.org/office/OpenDocument/v1.3/OpenDocument-v1.3-part3-schema.html#element-table_table — tables/rows/cells, optional nesting/merged/repeated structures; complex features are explicitly out of scope in this checkpoint. OWASP File Upload Cheat Sheet: file extension alone does not validate actual package contents.

## Exact source scope

- Accept only .odt local file, <=16MiB and strict ZIP beginning with exact first local member `mimetype`, method STORED (0), no ZIP extra field. Actual mimetype bytes = `application/vnd.oasis.opendocument.text`; `content.xml`, `META-INF/manifest.xml` required. Manifest root media-type must match package mimetype; reject encrypted members, external relationships/references, script/macros/executable/embedded attachments, hidden or unexpected package members and XML DTD/entities; reject duplicate and unsafe ZIP paths, ZIP bombs via existing `openSafeWorkbookArchive` limits.
- Only explicit strict ODT subset: office:document-content with expected namespace declarations; office:body > office:text > **direct** table:table > table:table-row > table:table-cell > text:p with plain text; optional table:table-column style definitions accepted but no repeats/merged cells/covered cells/nested rows or tables/automatic row expansions. Explicit ODT number-rows-repeated/columns-repeated, table spans/formulas/changed text, xlink external references, drawings/scripts, and mixed content FAIL CLOSED, not silently skipped. Style/header layout not interpreted. Limit <=20 tables, <=200 rows/table, <=16 cells/row, <=2000 total cells, <=4096 UTF-16 code units/cell, <=1MiB content.xml and bounded other members.
- Structure-only returns SHA256 of exact original ODT ZIP, profile `office.odt-tables.structural.v1`, `CONFIG_DOCUMENTED`, `REVIEW_REQUIRED`, `textIncluded:false`, `canActivate:false`, `engineVerified:false`, `physicalTopologyVerified:false`, table/row/cell ordinals, integer lengths, typed source locations. No raw ODT text, source cell hashes, inferred assets/links, Builder/Engine edits, export/mapping, disk persistence or network connections.
- Standalone file bridge and English modal in Import / Export with file picker and close, read-only text summary, source SHA, cell counts, and typed positions. Selecting another file clears stale results, errors show code only, async stale reads cannot overwrite newer source. No auto import adapter registration or external loads. DOCX P1–P6 and current other format UI paths unaffected.

## Scope honesty

ODT-P1/P2 does not support all valid ODT documents: complex office styles, nested/wrapped/repeated/merged tables or rich paragraphs can be rejected. It is NOT ODT value import, network inventory conversion, asset identity proof, actual topology validation or Engine PASS. Fail closed instead of guessing.
