## Frozen intended product behavior

1. Add a conspicuous **shared, bounded read-only XML inspection action** under the existing `Import / Export` menu. Supported file chooser hints `.graphml,.drawio,.nessus,.xml`; actual acceptance requires P1's validated producer-specific original-byte parser (GraphML, draw.io, Nmap XML, Nessus v2), never suffix alone. Retain existing individual preview/review/association actions and five active enterprise adapters unchanged.
2. The shared panel shows only `profileId`, `semanticTrack`, `status`, original SHA-256 + typed **document-level** locator, non-sensitive integer counts and a clear `canActivate=false` message. No source names, hosts/IPs, plugin output, credentials, XML, copied labels, or unescaped input. A blocked parser displays only a fixed reason code. Do not convert an `EVIDENCE_OBSERVED` scan to live Engine truth or a diagram edge to a physical cable.
3. Selecting a file **does not parse** until the user separately checks local inspection consent and clicks **Inspect selected XML (read-only)**. A changed file selection, unchecked consent, canceled chooser, Escape/Close (even while read is pending), or a changed live Builder/Runtime workspace resets consent and result, invalidates the in-flight job, and makes stale responses inert. Displaying a valid inspected file does not grant Builder activation or persistence.
4. The TypeScript browser file adapter validates claimed and actual byte lengths (<=2 MiB), actual ArrayBuffer, basename shape, then hands *original bytes* to P1. The P1 original-byte snapshot and source hash remain authoritative. No remote source fetch, filesystem path, XML execution, guest command, simulated probe or local-network access.
5. An in-flight file read may resolve after user changes files or closes the dialog. Its older success/failure must **never** repopulate the newer preview, restore consent, or show an old error. No file selection or content reaches output/debug logs.
6. **Node positive/adversarial tests:** source profile Nmap XML/Nessus/GraphML/draw.io, file-size/malformed/wrong-profile, secret canaries absent, React DOM escaped metadata-only and no import controls, P1/IC-000 plus unchanged CSV modeled probes.
7. **Actual compiled real Chromium tests in required PR CI and independent merged-main Linux release:** click real menu/file picker and explicit consent, inspect a valid XML and independent hash, inspect malicious XXE/spoof and ensure stale preview cleared, switch/close with an intentionally deferred genuine `File.arrayBuffer()`, verify no external HTTP requests, unchanged exported canonical Builder source, and no UI active-probe/Builder mutation. Test an invalid read/mismatched profile and real DOM against the mounted compiled app. Do not label a static source inspection as a browser run.
8. Required CI and Linux release must execute the newly added gate. Any failed assertion = no merge. GitHub Actions Ubuntu is enough for automated gates, Parrot-native and physical network NOT_RUN.
