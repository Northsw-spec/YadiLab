## Small scope
Implement one pure, source-content-blind **validation gateway** for the consented shared document inspection modal and an explicit UI review lifecycle. The actual producer parsers still select all eight profiles; **do not** re-parse in the UI or attempt a universal format detector.

The gateway must reject by fixed safe `IC010_P3D_RESULT_INVALID`:
- Unknown status, wrong profile, status/track/summary mismatch for all eight validated profiles, an invalid `sourceSha256`, a mismatched `documentLocator`, a model mutation or Engine/physical topology claim, noninteger/negative/overflow counts, contradictory source-bound locator counts, missing fields, new/unrecognized payload fields, raw cell/IP/host data, forged partial success payloads or blocked records that present a trusted SHA/summary.
- For blocked records, allow only known `IC010_XML_*`, `IC010_STATIC_*`, `IC010_P3C_*` fixed source error codes, with existing safely validated P1 XML `candidateProfileIds` (when present). Never render arbitrary `code` or `Error.message` or stringify a failed/unsafe object into DOM or a downloaded file.
- Preserve unmodified result key order, immutable source/result, summary, document locator, and the **P3b exact `JSON.stringify` re-read equality** contract, so genuine Ansible one-host review exports continue to work.
- Genuine graphml = `REVIEW_REQUIRED/TOPOLOGY_DECLARED/GRAPH_STRUCTURE`; drawio = `PREVIEW_ONLY/TOPOLOGY_DECLARED/DRAWIO_DIAGRAM`; Nmap/Nessus = `EVIDENCE_ONLY/EVIDENCE_OBSERVED` with their respective observation summaries; Ansible YAML/INI and DOCX/ODT = `REVIEW_REQUIRED/CONFIG_DOCUMENTED` with their respective documented summaries. Never reinterpret these statuses as verified physical links, current IP addresses, active probes or Engine PASS.
- Add one **derived**, not separately mutable lifecycle indicator in the existing consented modal: `NO_SOURCE`, `AWAITING_CONSENT`, `READY_TO_INSPECT`, `INSPECTING`, `REVIEW_REQUIRED`, `PREVIEW_ONLY`, `EVIDENCE_ONLY`, `BLOCKED`. Order is derived from actual selected file/consent/busy/result/error; file switch, cancel, withdrawal, Escape, dialog close/reopen and Builder workspace change must clear pending result and not carry consent across sources.
- The successful result panel must display a bounded fixed **status meaning** (not arbitrary source text) for each `TOPOLOGY_DECLARED`, `EVIDENCE_OBSERVED` and `CONFIG_DOCUMENTED`. Keep existing P2/P3a/P3b/P3c element selectors and text assertions and no file names/host content in these new fields. No automatic Builder changes or new import adapters.

## Explicitly out of scope
New parsing formats, universal XML/Office/Ansible import, cell-text disclosure, network graph activation, physical-link verification, live observations, probes, Engine PASS, new OSPF, auto-matching. The review gateway validates a parser-provided contract: it is **not** cryptographic verification against arbitrary hostile executable JS. The only trusted source hash comes from the existing producer's original-byte read. `IC-010` stays OPEN until common gate and future staged imports are complete; next assess **IC-010 gate and IC-020** from fresh main, avoiding invented P3 milestones.
