## Narrow feature
Operator may **explicitly choose up to 20 source vertex positions** from one locally read `.drawio` document and associate them one-to-one to existing Builder resources, exporting metadata-only sidecar. Source positions consist of `pageOrdinal` (0–15) and `vertexOrdinal` (0-based index among only vertex cells in that page's validated `root`). They are **not node IDs**, identity proof, actual mapping of a device, or demonstrated network topology. Drawn `mxCell edge=1` never yields a Builder connection or exported edge. The original source profile does not expose sensitive labels/IDs/endpoints, and P4 must preserve that. UI shows `Page #N / drawn vertex #N` ONLY, no source text, IDs, addresses, styles, source/target IDs, XML, or actual drawings. Default is no references, explicit select + acknowledgment of unverified status. Max 20, pages offered only as bounded list; no automatic mapping or de-duplication inference.

## Immutable source/model gate

Two selections on same page/ordinal or same target model resource blocked, no use of `__proto__`/constructor/prototype identifiers, each selection count 1–20.
- Require Builder scenarioId, sourceRevision, resources ID set; check exact current identities and valid target IDs at export. Reject missing Builder, changed scenario/revision/resource set, forged source hash, no acknowledgment, stale source/file race. Original local `.drawio` file re-read and **parsed with the same P3 bounded XML/decompression path**, original exact full-file SHA256 AND all page/vertex/drawn-edge/compressed counts rechecked at export. Safe errors `DRAWIO_ASSOC_*` or existing stable parser codes only; no sensitive XML or input strings in errors/DOM/logs.
- Snapshot the Builder **current at export completion**, not an earlier render closure; reject if it changes across asynchronous reads. Modal close, file-selection generation change, workspace revision change invalidates in-flight export. A stale async result must not trigger download or create a success status.

## Compatibility boundary
